# Computer science and AI adapter

State inputs, formal semantics, indexing, numeric model, and required output. Trace the
smallest decisive state sequence or derive the algorithm independently. Use
`scripts/cs_check.py` only for bounded traces, recurrences, graphs, truth tables,
shapes, or explicit complexity functions; use `finite_search.py`, `exact_math.py`, or
`text_transform.py` when the router recommends them.

Attack off-by-one behavior, empty input, indexing origin, mutation/hidden state,
integer versus floating point, overflow/truncation, worst versus average case, output
size versus runtime, encoding direction, and base/log conventions. Scripts do not
establish conceptual AI definitions or unspecified language semantics.

For conceptual logic, computability, or self-reference questions, first test whether
the named object is well-defined and whether existence or consistency was actually
granted. Separate what follows deductively from the premises from what is only analogous
to a familiar theorem or construction. Steelman each answer option as an exact claim;
an evocative analogy, name, or narrative fit is not entailment.
