# Image-dependent adapter

Locate the supplied image and inspect the complete frame before cropping. Record image
dimensions, then inspect bounded enlarged crops for small labels, axes, structures, or
geometry. Adjust contrast only when it helps visible inspection. Preserve surrounding
context and distinguish directly visible evidence from inference.

Use `scripts/image_prepare.py` for discovery, metadata, and optional preprocessing when
Pillow is already available. Never install packages or use the network. Route extracted
evidence to the subject adapter. Attack linear versus logarithmic axes, legend/color
mapping, object-label association, stereochemical bond direction, cropped-away context,
and diagrams not drawn to scale. OCR or preprocessing does not prove meaning.
